PURPOSE

This is a deletion classification, not a deletion script. Paths are relative to
the repository root. Nothing was deleted.

The attached file is a path-only tree: it does not contain byte sizes, content
hashes, modification times, Git tracking status, or the contents of manifests.
Accordingly, only caches, failed attempts, stale process markers, and clearly
regenerable previews are classified as SAFE TO DELETE NOW. Scientific outputs
and checkpoints are classified as conditional unless an independent frozen copy
is visible in the tree.

IMPORTANT VERSIONING RULE
-------------------------
Do not delete a path merely because its name contains v1, v2, or v3.

In this repository:

* causal v2/v3/v4 denotes the 70/31/29 operational merge, not three redundant
  copies of the same experiment;
* focused mechanism v5 and v7 correspond to different completed walk-forward
  windows/protocol corrections;
* synthetic-dose v1, presentation-response v2, terminal-robustness v1, and
  mixed-pretraining v1 are different experiments;
* frozen releases are immutable provenance, not ordinary build output.
